# 🧮 BMI Calculator – Python Project  
A simple and accurate Body Mass Index (BMI) Calculator built with Python. This tool calculates your BMI based on your height and weight, and categorizes it according to WHO standards.

## 📌 How It Works  
- User inputs height (in centimeters)  
- User inputs weight (in kilograms)  
- The program calculates BMI using the formula:  
BMI = weight (kg) / (height (m))².


- BMI is interpreted into categories like "Normal", "Overweight", "Obese Class I", etc.

 ## ✅ Features  
- Simple and user-friendly input  
- Accurate BMI calculation  
- WHO-standard BMI classification  
- Error handling for invalid input  

## 🚀 Getting Started  
1. Make sure Python is installed  
2. Run the script:  
```bash
python bmi_calculator.py
Follow the prompts to enter your height and weight
```
