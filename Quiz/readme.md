
# 🧠 CLI Quiz Game in Python

Welcome to the **Command-Line Quiz Game** — a fun, interactive trivia game you can run in your terminal! This app is designed using basic Python features and includes a variety of general knowledge questions with colorful visuals using the `colorama` module.

## 🎮 Features

- 💡 Multiple-choice quiz with 12 diverse questions
- 🎨 Colorful and animated terminal interface using `colorama`
- 💸 Prize money system with checkpoints
- ❌ Option to quit anytime and keep your winnings
- 🧼 Clean UI and code structure
- 🐍 100% Python, no frameworks required

## 📸 Demo

```
Question for ₹10000:
Who is the strongest character in anime?
a. Saitama 
b. Naruto 
c. Goku 
d. Satoru

Enter your answer (a/b/c/d) or 'q' to quit: c

🎉 Correct Answer! 🏆 Total Money: ₹10000
```

## 📦 Requirements

Make sure you have Python installed (3.x recommended). Also install the required module:

```bash
pip install colorama
```

## 🚀 How to Run

1. Clone this repository or download the script
2. Save the code as `quiz_app.py`
3. Open terminal/command prompt in the same directory
4. Run the app using:

```bash
python quiz_app.py
```

## 🎯 Gameplay Rules

- Answer each multiple-choice question by typing a, b, c, or d
- You can type `q` to quit the game at any time and keep your winnings
- Some milestones (₹20,000 and ₹100,000) are safe checkpoints — you won't lose below these
